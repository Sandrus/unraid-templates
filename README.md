# Sandrus Unraid Templates

Community Applications templates for Docker applications I use or want to make available on Unraid.

## Applications

### GAPS 2
GAPS 2 finds missing movies and TV shows from Plex, Jellyfin and Emby libraries.

Upstream project:
https://github.com/primetime43/GAPS-2

## Support

For application-specific issues, please use the upstream project's issue tracker.
For problems with the Unraid template itself, open an issue in this repository.
